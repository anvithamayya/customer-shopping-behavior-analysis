# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, spending behavior, discount usage, subscription behavior, and other business insights.

The project combines **Python, SQL, and Power BI** to perform data analysis and present the findings through visualizations and an interactive dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- SQL
- PostgreSQL
- Power BI

## 📂 Project Files

| File | Description |
|---|---|
| `customer_shopping_behavior.csv` | Dataset used for the analysis |
| `customer_shopping_behavior_analysis.ipynb` | Python-based data analysis and exploration |
| `customer_shopping_behavior_queries.sql` | SQL queries used for business analysis |
| `customer_shopping_behavior_dashboard.pbix` | Power BI dashboard |

## 🔎 Analysis Performed

The project analyzes several aspects of customer shopping behavior, including:

- Revenue generated by male and female customers
- Customers who used discounts while spending above the average purchase amount
- Products with the highest average review ratings
- Comparison of average purchase amounts between Standard and Express shipping
- Spending and total revenue comparison between subscribers and non-subscribers
- Products with the highest percentage of discounted purchases
- Customer segmentation based on previous purchases
- Top purchased products within each category
- Subscription behavior among repeat buyers
- Revenue contribution across different age groups

## 🐍 Python Analysis

Python and Pandas were used for data analysis and exploration.

The Jupyter Notebook contains the Python-based analysis and supporting outputs and visualizations.

## 🗄️ SQL Analysis

SQL was used to answer business-oriented questions from the customer dataset.

The queries include:

- Aggregation and grouping
- Filtering
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- Customer segmentation
- Revenue analysis
- Product-level analysis

## 📊 Power BI Dashboard

A Power BI dashboard was created to present the customer shopping behavior analysis through interactive visualizations.

The `.pbix` file can be opened using **Microsoft Power BI Desktop**.
